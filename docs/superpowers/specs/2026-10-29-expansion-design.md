# Magic Survival Lab 확장 기획안 — 균열 원정

작성: 2026-10-29 · 상태: 제안 · 대상: 현재 HTML/Canvas 시제품의 다음 버전

> 이번 산출물은 공개 GitHub 저장소와 확장 기획안이다. 아래 신규 기능·수치·일정은 제작 제안이며 아직 구현되지 않았다. 기존 5분 게임의 동작 기준은 [DESIGN.md](../../../DESIGN.md)가 유지한다. 별도 표기가 없는 신규 규칙과 수치는 원작의 규칙이 아니라 이 팬게임의 초안이다.

## 1. 만들 게임

**한 손으로 움직이고 자동으로 마법을 쏘는 생존 게임에, 매번 달라지는 맵 현상과 조합의 행동 변화를 더한다.**

원작을 좋아하는 이유인 단순한 조작, 마법이 쌓이며 커지는 전투, 조합을 완성하는 기대감을 유지한다. 확장의 중심은 숫자와 아이콘 추가보다 다음 세 가지다.

1. **균열 현상:** 같은 맵에서도 이동 경로와 위험 판단이 달라진다.
2. **조합 공명:** 완성한 조합을 한 번 더 바꾸되, 장점과 대가를 함께 선택한다.
3. **보스 원정:** 오래 버티는 것과 함께 읽고 피해서 끝내는 목표를 제공한다.

작업명은 ‘균열 원정’으로 제안한다. 원작의 공식 확장판이나 원작 실행 파일의 모드로 표시하지 않는다. 지금 있는 별도 브라우저 게임을 확장한다.

## 2. 참고 근거와 현재 출발점

### 원작에서 확인한 내용

[공식 Google Play 페이지](https://play.google.com/store/apps/details?id=com.vkslrzm.Zombie)는 leme의 Magic Survival을 한 손으로 조작하며 다양한 마법으로 몰려오는 정령을 처치하는 게임으로 설명한다. 2026-10-29 조회 시 업데이트 표시는 2026-09-26이었고, 공개 변경 내역에는 v0.994의 마법 개선과 v0.993의 궁극 마법·아티팩트·몬스터·시너지 변경이 있었다.

이 문서에서는 원작의 최신 마법 개수, 조합식, 연구 비용, 클래스 수치를 확정 사실로 사용하지 않는다. 직접 최신 버전을 전체 플레이해 비교한 자료는 아니다. 원작의 콘텐츠 양을 따라잡는 것보다 새로운 플레이 판단을 만드는 데 집중한다.

[TomkoSK/magic-survival-builder](https://github.com/TomkoSK/magic-survival-builder)와 [실행 사이트](https://tomkosk.github.io/magic-survival-builder/)는 마법·연구·유물을 고르고 빌드를 계산하는 도구다. 플레이 가능한 생존 게임의 엔진 소스가 아니다.

현재 로컬 자료는 [고정 커밋 d58d531](https://github.com/TomkoSK/magic-survival-builder/tree/d58d53117e6bead22ee08f0ecac7bff9658ae922)에 기반한다. 원작의 현재 버전과 데이터 시점이 다르므로, 이 저장소의 이름·이미지 목록이 최신 원작 전체를 나타낸다고 가정하지 않는다.

### 이번에 하지 않는 것

온라인 계정, 서버 랭킹, 멀티플레이, 결제·광고, 가챠, 일일 숙제, Godot/Unity 전환은 제외한다. 원작의 전체 아이콘을 전투 콘텐츠로 한꺼번에 구현하는 작업도 제외한다. 이미 다운로드한 파일을 지우거나 원본 위에 생성 이미지를 덮어쓰지 않는다.

첫 시제품의 성공은 원정 1회를 시작해 선택·공명·보스·결과까지 완주할 수 있고, 기존 5분 모드가 그대로 작동하며, 플레이어가 두 빌드의 행동 차이를 설명할 수 있는 상태다. 아래 테스트와 기기 검증을 함께 충족해야 한다.

## 4. 한 판의 흐름

**시작 화면 → 모드/맵 선택 → 이동·자동 공격 → 마법 강화/유물 → 사건과 공명 → 최종 보스 → 결과와 빌드 기록**

첫 시제품은 기존 황혼의 폐허를 사용한다. 3개 맵의 연속 여행이나 이동 로딩 화면을 만들지 않는다. v1에서는 한 판 시작 시 맵 하나를 선택하고 끝까지 그 맵에서 싸운다.

| 구간 | 최대 10분 시제품 | 최대 15분 v1 |
|---|---|---|
| 도입 | 0–2분: 기본 마법 확보, 위험 예고 학습 | 0–3분: 동일 목적 |
| 구성 | 2–5분: 사건·유물·첫 조합 | 3–7분: 동일 목적 |
| 전환 | 5분 이후: 조건을 갖춘 공명 선택 1회 | 7분 30초 이후: 동일 목적 |
| 압박 | 5–8분 30초: 현상 강화, 빌드 약점 확인 | 7–13분 30초: 동일 목적 |
| 결전 | 8분 30초 보스 등장, 10분 마감 | 13분 30초 등장, 15분 마감 |

보스를 처치하면 즉시 승리한다. 제한 시각까지 보스를 못 잡으면 ‘균열 붕괴’로 패배한다. 동일 업데이트에서 여러 조건이 발생하면 **플레이어 사망 → 제한시간 도달 → 보스 처치** 순서로 판정한다. 기존 5분 모드는 시간 생존 승리 규칙을 유지한다.

시간은 실제 전투 중에만 흐른다. 강화·유물·사건·공명·일시정지·배경 탭에서는 멈춘다. 정예와 레벨업, 보스 종료가 겹쳐도 화면이 두 개 열리거나 보상이 중복 적용되지 않아야 한다.

원정의 마법 장착 수는 최대 6종, 마법 레벨은 현재처럼 최대 5, 활성 조합은 최대 3개를 제안한다. 이미 장착한 마법은 계속 강화할 수 있다. 6종을 채우면 새 마법 후보를 제외한다. 기존 퀵 모드에는 새 슬롯 제한을 적용하지 않는다.

## 5. 확장 시스템

### A. 균열 현상: 맵이 플레이 방식을 바꾼다

맵은 색상만 다르게 만들지 않는다. 경고 영역·안전한 이동 경로·회피 템포가 달라야 한다. 현상은 한 번에 하나만 활성화하고, 보스의 큰 공격과 겹치면 현상 공격을 잠시 유예한다.

| 맵 제안 | 전투 규칙 | 해당 보스 | 제작 순서 |
|---|---|---|---|
| 황혼의 폐허 | 위치가 예고된 균열이 시간차로 터짐. 움직이며 빈 구역을 찾아야 함 | 균열 파수자 | 첫 시제품 |
| 잿빛 관측소 | 회전하는 위험 띠 사이에 안전한 통로가 생김. 좁은 통로의 진로를 선택 | 맹목의 관측자 | v1 |
| 가라앉은 정원 | 독성 지면이 서서히 퍼지고 정화 지점으로 이동할 수 있음 | 침식의 뿌리 | v1 |

첫 시제품의 균열은 플레이어 현재 위치를 즉시 때리지 않는다. 경고 후 최소 0.8초 뒤 판정한다는 값을 초기 가설로 두고 모바일에서 조정한다. 색뿐 아니라 테두리·무늬·차오르는 표시로 경고와 유효 피해 구간을 구별한다.

### B. 조합 공명: 한 번 더 고르는 빌드의 성격

기존의 ‘두 마법 Lv.3 → 조합 선택’은 유지하고 재료도 소모하지 않는다. 공명은 원정에서 한 번만 선택하는 별도 변화다. 조합을 여러 개 보유해도 공명 횟수는 늘지 않는다.

시제품에서는 5분 이후 플라즈마를 보유하면 전투가 멈추고 세 후보를 보여 준다. 플라즈마를 나중에 얻으면 그때 한 번 제공하며, 끝까지 얻지 못한 빌드에는 강요하지 않는다. 첫 구현의 공명 지원 조합은 플라즈마 한 종뿐이라고 UI에 표시한다.

| 선택 | 플레이 변화 | 대가·한계 |
|---|---|---|
| 안정 | 플라즈마를 유지하며 소폭의 기본 피해 보너스 | 행동 변화가 적은 기본 선택 |
| 분열 | 광선이 부채꼴 세 갈래로 갈라져 군중을 정리 | 갈래당 피해 감소, 같은 적 중복 명중 제한 |
| 집속 | 광선 폭은 좁지만 먼 거리와 단일 강적에 유리 | 폭 감소, 시전 간격 증가 |

각 선택은 실제 피해·폭·주기 변화를 카드에 숫자로 비교한다. 분열이 무조건 세 배 피해가 되거나 집속이 군중전까지 압도하지 않도록 별도 검증한다. 정확한 배율은 플레이 테스트에서 조정한다.

### C. 사건: 짧은 위험과 보상

시제품 사건은 전투 시간 1분 30초, 3분 30초, 5분 30초에 한 번씩 등장한다. 접근 전에는 효과가 없고, 상호작용하면 전투를 멈춰 비용·보상·거절을 보여 준다. 보스 중에는 새 사건을 만들지 않는다.

| 사건 | 선택 | 제약 |
|---|---|---|
| 깨진 마나 샘 | 즉시 소량 회복 또는 경험치 획득 | 둘 중 하나만, 최대 체력 초과 회복 없음 |
| 봉인 제단 | 체력 1을 내고 미보유 유물 후보 획득 또는 거절 | 현재 체력 2 이상일 때만 지불 가능 |
| 불안정한 표본 | 일정 전투 시간 동안 적 압박 증가 후 보상 또는 거절 | 위험 수치와 보상 종류를 선택 전에 공개 |

대화 중에는 위험 시간이 흐르지 않는다. 거절은 무료이며 같은 사건이 다시 열리지 않는다. 선택·재진입·중복 클릭으로 비용과 보상이 두 번 적용되지 않도록 사건 ID와 완료 상태를 저장한다.

### D. 보스: 체력만 많은 적에서 벗어난다

첫 보스 ‘균열 파수자’는 현재 정예와 분리된 상태·체력·패턴을 갖는다. 처음에는 신규 스프라이트가 없어도 판독 가능한 도형으로 패턴부터 검증하고, 이후 제작 아트를 연결한다.

- 1단계: 플레이어 위치를 예고하는 원형 파열과, 사이를 지나갈 수 있는 방사형 파열을 번갈아 사용한다.
- 체력 50% 이하: 예고 횟수와 이동 압박을 늘리되 새 규칙을 설명 없이 즉사 공격으로 추가하지 않는다.
- 화면 밖에서는 방향 표시와 거리 표시를 제공한다. 플레이어가 도망가도 보스가 영구히 사라지지 않는다.
- 강제 밀치기·흡인·둔화는 보스에게 감쇠 적용한다. 영구 행동 불능을 허용하지 않는다.
- 피해 영역은 원화의 빛 번짐과 분리하고 경고 종료 후 활성화한다. 멈춘 화면에서는 패턴도 멈춘다.

v1의 관측자·뿌리는 각각 회전 통로와 지면 정화 규칙을 확장한다. 보스마다 최종 패턴과 아트 콘셉트를 별도로 확정하고 첫 시제품에는 넣지 않는다.

| 임시 이름 | 전투 역할 | 화면에서 구별할 핵심 |

| 암영침 | 적에게 표식을 남겨 후속 공격의 작은 추가 피해를 유도 | 얇은 침과 적 위의 짧은 표식 |
| 성운핵 | 잠시 모으고 터지는 지연형 군중 제어 | 수축하는 외곽선, 폭발 전 예고 |
| 유리파편 | 일정 횟수 튕기는 산탄형 공격 | 각진 파편과 튕긴 경로 |
| 봉인륜 | 일정 범위의 적을 잠시 약화하는 방어형 마법 | 플레이어 주변의 끊어진 고리 |

투사체·지연 공격·영역·상태는 현재 `projectiles`, `strikes`, `zones`, `effects`를 먼저 재사용한다. 표식 중첩 수, 흡인 거리, 튕김 횟수, 보스 저항과 이펙트 수에는 상한을 둔다.

### 추가 조합 4종

| 임시 이름 | 재료 제안 | 행동 변화 |
|---|---|---|
| 잔향의 서약 | 암영침 Lv.3 + 마나 창 Lv.3 | 표식이 붙은 적 처치 시 가까운 적에게 잔향 전이 |
| 진공 묘지 | 성운핵 Lv.3 + 소용돌이 Lv.3 | 지속 영역이 짧은 수축 후 폭발하는 리듬으로 변화 |
| 파쇄 성단 | 유리파편 Lv.3 + 운석 Lv.3 | 운석의 파편이 제한 횟수 튕김. 단일 적 다중 피해 제한 |
| 정지의 장막 | 봉인륜 Lv.3 + 냉기 Lv.3 | 경계에 진입한 적에게 약화·둔화. 무적이나 무한 빙결 아님 |

새 조합은 우선 기존 조합과 같은 Lv.3 규칙으로 구현한다. 여러 후보를 충족했을 때 하나만 영구적으로 가려지지 않아야 한다. 장착 슬롯으로 완성 불가능해진 조합은 도감에서 이유를 설명한다.

### 추가 유물 8종의 역할

이름·수치는 임시안이다. 기존의 단순 공격력·속도 보너스와 겹치지 않도록 행동 조건을 중심으로 구성한다.

| 임시 이름 | 역할 | 필요한 제한 |
|---|---|---|
| 잔향 고리 | 일정 횟수 시전마다 약한 추가 투사체 | 추가 시전이 자신을 다시 발동하지 않음 |
| 잿빛 도화선 | 지속 영역이 끝날 때 작은 폭발 | 영역당 1회, 사라짐과 중복 발동 구별 |
| 바늘 시계 | 시전 속도를 얻고 개별 피해를 낮춤 | 실제 기대 피해와 체감 주기 비교 |
| 맹목의 프리즘 | 사거리 증가 대신 최대 체력 감소 | 현재 체력을 안전하게 보정하고 선택 전 경고 |
| 접지침 | 피격 후 제한 주기의 방어 충격파 | 연속 충돌로 무한 발동하지 않음 |
| 균열 여과기 | 사건의 위험 시간을 줄이는 대신 보상도 축소 | 위험과 보상 둘 다 카드에 표시 |
| 자철독 | 잠깐 정지하면 수집 범위가 넓어짐 | 이동하면 해제, 가상 조이스틱 흔들림 기준 검증 |
| 유리 부적 | 체력이 낮을 때 제한적으로 방어막 획득 | 재발동 대기와 1회 소모 표시 |

## 7. v1에서 이어갈 성장

4개 시작 특성은 각각 투사체, 지속 영역, 근접 회전, 생존 보조를 강조한다. 특성 선택이 추가 조작 버튼을 요구하지 않아야 한다. 초기에 모두 시험 가능하게 열어 두고, 이후 해금은 관련 조합·보스 경험을 통해 다른 선택지를 여는 방식으로 설계한다.

연구 12개 노드는 v1 후반 작업이다. 전투 드롭 재화의 수치 경제는 첫 시제품에서 만들지 않는다. 연구는 필수 공격력 누적보다 시작 후보·수집 편의·빌드 선택지처럼 제한된 준비 옵션을 우선한다. 장착 포인트 상한과 무료 재설정을 제공하며, 연구가 없어도 기본 원정을 클리어할 수 있어야 한다.

노드별 비용·효과·해금 조건은 실제 10분 원정 데이터 이후 별도 밸런스 표로 확정한다. 기획에 적었다는 이유로 현재 저장 데이터에 임의로 구현하지 않는다.

## 8. UI와 조작

현재 [DESIGN.md](../../../DESIGN.md)의 패널·색상·키보드 포커스·모바일 조작을 확장한다. PC의 우측 마도서와 모바일 하단 장착 바를 재사용한다.

- 시작: 5분 모드와 원정을 구별하고 원정의 최대 시간·보스 목표를 표시한다. 미구현 맵은 플레이 가능한 것처럼 표시하지 않는다.
- 전투: 시간, 체력, 경험치, 보스 방향, 공명 여부를 우선한다. 모든 마법의 긴 설명을 화면 위에 상시 배치하지 않는다.
- 선택: 획득/강화/조합/공명을 구분하고 현재 효과와 변경 후 효과를 비교한다. 선택 중 전투는 정지한다.
- 정지: 보유 마법·레벨·유물·조합·공명·맵 현상을 확인한다. 작은 아이콘만으로 효과를 설명하지 않는다.
- 결과: 모드, 맵, 결과 이유, 전투 시간, 빌드, 공명, 보스 처치 여부를 기록한다. 한 번 더 시작하는 버튼을 제공한다.
- 모바일: 새 회피·스킬 버튼 없이 이동만으로 완주 가능해야 한다. 엄지손가락 아래에 위험 표시를 가리지 않는다.

390×844와 320×740 화면에서 가로 넘침·선택 버튼 가림·스크롤 충돌을 검사한다. 색각만으로 공격을 구분하지 않고, reduced-motion에서는 화면 흔들림과 비필수 번쩍임을 줄인다. 사진처럼 복잡한 배경이 적과 투사체를 가리지 않게 한다.

## 9. 이미지 생성 및 에셋 제작 계획

### 참고할 것과 새로 만들 것

확보한 이미지는 검은 배경 위의 밝은 중심 형상, 거친 질감, 제한된 발광색을 파악하는 참고판으로 사용한다. 예를 들어 현재 `manaSpear.png`는 푸른 입자 속의 밝은 사선, `abyss.png`는 보랏빛으로 모이는 구조를 가진다. 신규 이미지는 이런 큰 시각 원칙을 공유하되, 모양·중심 상징·구도는 새로 설계한다.

업스트림에는 확인 가능한 LICENSE가 없다. 출처 표기가 재배포나 변형 허가를 대신하지 않는다. 원본 다운로드 파일은 그대로 보존하고 신규 생성물은 별도 경로에 둔다. 공개 배포 준비 시 원본 이미지·폰트의 사용 조건을 확인하거나 대체한다. AI로 비슷하게 만들었다는 사실만으로 권리 문제가 자동 해소됐다고 처리하지 않는다.

### 먼저 제작할 묶음

| 우선순위 | 산출물 | 첫 납품 범위 |
|---|---|---|
| A: 스타일 시험 | 신규 마법 아이콘 4개 | 실제 UI 크기에서 구별되는지 먼저 검토 |
| B: 시제품 콘텐츠 | 신규 조합 4개 + 신규 유물 8개 | A와 같은 여백·대비·질감 |
| C: 전투 개체 | 일반 적 변형, 고속 적, 정예, 균열 파수자 | 충돌 반경과 그림 크기를 별도로 정의 |
| D: 배경 | 폐허 바닥·장식·균열 경고/활성 효과 | 반복 경계와 지형 가독성 검증 |
| E: v1 | 두 번째·세 번째 맵과 보스, 특성·연구 아이콘 | 시제품 검증 이후 수량 확정 |

아이콘은 1024×1024 원본에서 검토 후 512×512 배포본을 만든다. 신규 아이콘의 오브젝트 레이어는 투명 PNG로 제작하고 카드 배경은 UI가 담당한다. 기존 원본의 검은 배경을 일괄 삭제하거나 비율을 강제로 정사각형으로 바꾸지 않는다. 32px·48px에서도 중심 형상이 읽혀야 한다.

플레이어·적은 목표 게임 내 크기 64px 또는 128px를 기준으로 크기와 방향을 맞춘다. 처음에는 정지 그림과 코드의 이동·피격 표현으로 검증한다. 걷기 4프레임 등을 만들 경우 프레임별 포즈·피벗을 확인한다. AI가 그린 격자 그림을 실제 정합된 스프라이트 시트로 간주하지 않는다.

맵 타일은 반복 이음새가 없는지 별도 확인하고 경고 영역은 코드로 그린다. 보스 원화의 발광 테두리가 피해 영역처럼 보이지 않게 한다. 적·바닥·장식·마법 이펙트는 한 장에 합치지 않는다.

### 생성 프롬프트 예시

**암영침 아이콘:** ‘어두운 판타지 생존 게임용 독자적인 마법 아이콘. 비대칭으로 갈라진 세 조각의 흑요석 침, 중앙의 작은 청록빛 점과 듬성한 거친 입자. 기존 게임의 문양·로고·문자를 재현하지 않는다. 높은 명암 대비, 제한된 발광, 32px에서도 읽히는 단일 중심 실루엣, 정사각형, 오브젝트 외부 투명 배경.’

**균열 파수자 콘셉트:** ‘탑다운 전투용 독자적인 폐허 수호체. 떠 있는 세 개의 불균형 석판과 비어 있는 중심부, 낮은 채도의 돌과 작은 호박색 핵. 넓고 명확한 실루엣, 위에서 내려다본 동일 시점, 원화 바깥 투명 배경. 바닥·UI·문자·공격 경고 원은 제외. 특정 기존 캐릭터의 형태나 상징을 복제하지 않는다.’

후보는 실제 게임 배경에 올려 비교한다. 선명도·형태 일관성·투명 가장자리·크기·충돌 판독·모바일 축소 상태를 통과한 파일만 연결한다. 이미지 생성 자체와 전투 구현 완료를 별도로 기록한다.

### 파일과 출처 관리

신규 경로 예: `assets/generated/magic/shadow-needle-v01.png`, `assets/generated/bosses/rift-warden-idle-v01.png`. 기존 `assets/*Images`와 원본 manifest는 유지한다.

신규 manifest에는 ID, 파일 경로, 역할, 픽셀 크기, 투명 여부, 프레임/피벗, 생성 도구·모델, 프롬프트, 참고한 출처와 커밋, 생성 시각, 해시, 사용 조건 확인 상태, 게임 연결 상태를 남긴다. 인증 토큰·계정 정보는 기록하지 않는다. 생성 시각과 모델 정보는 실제 실행 결과로 채우며 지금 임의로 만들지 않는다.

## 10. 기술 구현 방향

HTML/CSS/JavaScript/Canvas와 ES modules를 유지하고 새 의존성을 추가하지 않는다. 엔진 전환을 선행하지 않는다. 데이터 목록과 전투 규칙이 이미 분리된 구조를 사용한다.

| 파일/영역 | 확장할 책임 |
|---|---|
| `core.mjs` | 모드별 제한시간·종료 규칙, 원정 슬롯, 신규 마법·유물, 사건·공명·보스의 상태와 판정 |
| `game.js` | 새 상태의 표시, 입력 연결, 경고 영역, 보스·공명·결과 렌더링, 저장 경계 |
| `index.html` / `style.css` | 기존 선택·정지 패널 확장, 원정 선택, 효과 비교와 모바일 배치 |
| `build.mjs` | 실제 사용한 신규 에셋만 단일 `play.html`에 포함 |
| `build-atlas.mjs` | 원본 자료와 신규 생성물, 실제 구현 상태를 구별하는 도감 표시 |
| `tests/` | 모드 회귀, 조합 조건, 사건 비용, 공명 중복, 보스 패턴과 종료 경계 |

보스도 피해·위치 같은 공통 적 처리를 활용하되, 일반 적 개수에 끼워 넣어 별도 종료 규칙을 생략하지 않는다. 새 시스템마다 만능 관리자·플러그인 프레임워크를 만들지 않는다. `core.mjs`가 실제로 커져 독립 단위가 생겼을 때 그 단위만 모듈로 분리한다.

초기 성능 예산은 적 300, 발사체 400, 지속 영역 24개 정도를 **측정용 가설**로 둔다. 현재 한도가 이 숫자라는 뜻은 아니다. 정한 상한을 넘으면 오래된 장식 효과를 먼저 줄이고, 피해 판정이 임의로 사라지는 방식으로 숨기지 않는다. PC 60fps, 중급 휴대폰 지속 30fps 이상을 목표로 실측한다. 미달하면 효과·상한·판정 빈도를 측정 후 조정한다.

### 저장 호환

기존 최고 시간·처치 수는 유지한다. 원정 기록을 추가할 때 버전이 있는 별도 저장 구조를 도입하고 유효한 옛 기록만 변환한다. 모드·맵별 기록을 분리해 5분 기록과 15분 기록을 섞지 않는다.

저장 JSON 손상, 알 수 없는 콘텐츠 ID, 저장 차단·용량 부족에서도 플레이는 가능해야 한다. 실패한 저장을 성공으로 안내하지 않는다. 첫 원정 시제품은 한 판 도중 저장/재개를 지원하지 않으며 새로고침하면 그 판은 종료된다. 향후 중간 저장은 난수 상태와 보상 중복 문제를 별도 설계한 뒤 추가한다.

## 11. 제작 순서와 검증

작업량은 달력 날짜를 약속하지 않고 단계별 완료 기준으로 관리한다.

1. **현재 기준선 보존:** 5분 모드의 25개 기존 테스트와 빌드 결과를 기준으로 남기고, 모드 설정과 결과를 구별한다. 새 원정에서도 퀵의 제한·기록이 바뀌지 않는 회귀 검증을 추가한다.
2. **첫 원정 완주:** 기존 마법·배경으로 10분 원정, 보스 1종, 원정 결과까지 연결한다. 보스 경고·정지·사망·시간 경계부터 검증한다.
3. **빌드의 변화:** 신규 마법 4·조합 4·유물 8과 슬롯 표시, 플라즈마 공명을 연결한다. 각 콘텐츠의 행동 차이와 중복 방지를 검증한다.
4. **균열과 사건:** 맵 현상 1종과 사건 3종을 연결한다. 비용 지불, 거절, 정지, 보스와의 중첩을 검증한다.
5. **신규 아트와 실제 플레이:** 스타일 시험 → 확정된 에셋 연결 → PC/모바일 비교 → 실제 기기 원정 완주 순서로 진행한다. 파일 확보와 게임 연결을 각각 기록한다.
6. **v1 확장 판단:** 완주·실패 이유와 조작 피드백을 보고 15분·추가 맵·특성·연구를 진행한다. 기본 원정이 지루하거나 불명확하면 수량 확장을 미룬다.

### 수직 시제품의 통과 조건

| 검증 | 통과 조건 |
|---|---|
| 기존 기능 | 기존 테스트 25개, 문법 검사, 빌드가 모두 통과. 5분 종료·기록·입력 유지 |
| 원정 종료 | 보스 출현 시각, 처치 승리, 시간 패배, 사망 우선순위가 결정적으로 재현됨 |
| 조합/슬롯 | 6슬롯 제한이 원정에만 적용됨. 미충족 조합·중복 조합을 선택할 수 없음 |
| 공명 | 한 판 1회, 선택 전 효과 변화 없음, 3갈래가 실제 판정을 다르게 함 |
| 사건 | 체력 비용으로 사망하지 않음. 거절은 무료. 같은 사건의 비용·보상 중복 없음 |

| 실제 기기 | PC와 실제 휴대폰에서 각각 원정 완주 및 패배·재시작, 중간 정지·탭 전환 확인 |

헤드리스 테스트, 모바일 뷰포트 에뮬레이션, 실제 휴대폰, 사람의 밸런스 평가는 각각 PASS/FAIL/NOT_RUN으로 기록한다. 테스트를 통과했다고 실제 기기나 재미가 검증됐다고 쓰지 않는다.

첫 플레이 평가는 서로 다른 빌드로 최소 3회 진행한다. 기록할 항목은 첫 조합 시각, 공명 선택 이유, 체감상 불가피한 피격, 보스 패턴 이해, 빈 시간, 최저 프레임이다. 공명 두 선택이 같은 경험을 주거나 특정 선택만 합리적이면 분기 수량을 늘리기 전에 수정한다.

## 12. 결정과 남은 작업

이번 제안의 기본값은 **HTML 유지, 기존 5분 보존, 10분 원정 하나부터 완주, 새 이미지 별도 제작, 이후 15분과 3개 맵으로 확장**이다. 이는 작성자가 잡은 초안이며 사용자가 확정한 콘텐츠 수나 밸런스 정책으로 취급하지 않는다.

다음 제작 작업의 첫 단위는 ‘기존 배경과 마법으로 보스를 포함한 10분 원정 1회 완주’다. 아트 수십 장 생성이나 연구 경제 구현부터 시작하지 않는다. 이미지 제작은 마법 아이콘 4개로 스타일을 먼저 확인하고, 전체 세트 확장은 실제 연결과 플레이 결과에 따라 진행한다.

남은 검증: 최신 원작의 직접 플레이 비교, 신규 원정의 실제 구현, 이미지 생성, 실제 기기 전체 런, 원본 이미지·폰트의 공개 배포 조건 확인. 이 문서 작성만으로 어느 항목도 완료 처리하지 않는다.
