# 1.0 확장 개발 빌드 검증표

이 문서는 코드·자동 검사·실행 산출물·기기/사람 수용을 구분한다. 버전1.0.0은 개발용 debug 서명 빌드이며 스토어 승인이나 사람의 최종 밸런스 수용을 뜻하지 않는다.

## 구현 범위

- 15분 캠페인,13분30초 보스. 기존5분 퀵·10분 원정과 기록 경로는 보존.
- 24마법·36융합·96유물,6지역·보스·시작 계열,일반 적24변종·정예18종.
- 사건12개(배치→접근→실제 비용·효과 선택),지원 융합4개의 공명12분기.
- 연구24개·6장착,거점 구매/설정,독립 프로필의 지역 기록·발견·원자적 보상 정산.
- 오프라인 시드 도전·보스 연습의 보상/기록 분리. 물리 WASD/P/1–3과 방향키·화면 드래그.
- 허브 고정 탭/시작 영역,검색 가능한 도감,기본 접힘 조합식,명시적인 무보상 포기,모달/앱 배경 정지.

[전투 구현](campaign-core.md),[96유물 항목별 효과·소비 지점·검사](artifact-coverage.md),[화면·연구 연결](campaign-ui.md),[독립 코드 검토](independent-core-review.md).

## 그림과 원본

6개 지역의 메뉴/전장을 별도 이미지로 제공한다. Z02-Z06의10개PNG와 B02-B06의5개 투명 보스PNG는 실제 imagegen 결과로 제작하고 원본·프롬프트·SHA-256을 보관했다. Z01/B01은 기존 생성 자산을 유지했다. 다섯 보스는 구형 렌즈/넓은 뿌리/긴 유속 형상/각진 유리/방송 신호 실루엣으로 구분한다. 충돌 반경은 그림 크기와 독립적인 기존 판정을 유지한다.

132개 신규 선택지에는 제공 저장소의126개 PNG를 수정 없이 역할에 맞춰 연결했다. 그중 일부는 문자 그대로의 물건 대신 상징을 택한 큐레이션이며 해당 이미지의 원작 이름을 새 디자인의 정체성으로 주장하지 않는다. [아이콘 출처](icon-provenance.md)와 `godot/data/release_icons.json`을 참조한다. 원작 자료관464개와 실행 콘텐츠 수는 별개다.

## 검증 근거

- 레거시·카탈로그·진행·전투·융합·조우·정산·유물·UI 검사를 별도 suite로 수행. 최신 수치는 아래 최종 실행/CI에 기록한다. 검사 개수만으로 동작을 대신하지 않는다.
- 유물96개 모두 개별 효과 assertion과 제안→선택→중복 거절 경로를 연결했다. 획득 조건을 만족하는 합법적인 C01 마법 구성의 최대치는4개였다. 이 검사는 풀이 소진된 통제 fixture이며 보통 플레이의 드롭 분포·시점 검증이 아니다.
- 같은 프레임 실제 피해로 보스 처치→사망/마감/승리→프로필 정산을 연결한30개 검사. 최종 패배는 정상 생존·사건·첫 대면만 지급하며 보스 승리/첫 클리어를 지급하지 않는다.
- 6개 고정 시드에서 정상 API로만 게임을 진행한 봇 검사:3승,1시간초과,2사망,런타임/불변식 오류0. C06은 실제로 XP를 모아 성장했고 C01의30초 동일 입력 재현이 일치했다. [전체 데이터와 한계](automated-playability.md). 실제 사람이 느끼는 재미나 모든 클래스의 난이도 승인을 뜻하지 않는다.
- 독립 시각 검토는 통제된 GPU 캡처로 원작 미술 언어·여섯 지역·선택 카드·위험 도형·실습·A041 윤곽을 검토했다. 추가 허브/보스 판정은 최종 캡처 결과에 덧붙인다.
- Godot이 스크립트 오류에도0으로 종료하는 사례를 재현해 CI는 종료 코드·오류 로그·실제 양수 검사 완료 문구를 모두 확인한다. 의도적으로 없는 검사로 실패 검출도 확인했다.
- Web PCK는 빈 프로젝트 디렉터리에서만 로딩해 신규 아이콘132개와 지역 그림10개,실행 스크립트·JSON 및 테스트 제외를151개 항목으로 검사했다. Android APK에서도 동적 리소스 import대상과 JSON 포함을 검사했다.
-100쪽 GDDv0.6:원고 누락/빈 페이지/경계 넘침0,108북마크43링크,표 최소 글자8.5pt이상. C06의M15 최소 피해와M07의캠페인 고체력 표적,동시 종료 정산 정책을 원고와PDF에 함께 반영했다.

## 실제 실행 확인과 남은 수용

Android36/16KB 페이지 에뮬레이터에서 실제 캠페인Z04/C01을 시작해 오른쪽 위 드래그·Back정지·중복Back·홈/복귀를 확인했다. 정상 플레이76.23초/70처치 실패로 연구 잔재2가 지급됐고,앱을 완전히 재기동한 뒤 파일과 UI에서 잔액2와 지역 기록이 유지됐다. 부족한 잔액으로 연구를 구매해도 파일은 바뀌지 않았다. 테스트용 가짜 잔액을 운영 프로필에 넣지 않았다.

연결된 실물 휴대폰은 확인되지 않았다. 실제 기기별 프레임/발열/잘림,사람의 전체 원정·모든 계열 밸런스,일반 드롭 분포,스토어 배포와 외부 자산 권리 수용은 별도다. 코드/자동/에뮬레이터 증거를 해당 수용으로 바꾸지 않는다.2.x 목표48/72/180과추가지역/보스/공명은이번1.0에포함하지않는다.

최종 APK·웹·공개 배포 식별자는 아래 공개 전달 결과에 기록했다.

## 최종 통합 체크포인트

네이티브14개 suite **1822검사**와 HTML참조35검사를 통과했다. 독립 코드 검토의 원래8건·추가 유물 소비자·최종 정산 연결을 수정했고, 실제 피해→보스처치→동시종료→정산30검사를 CI에 포함했다. 물리키·폰트·고정 허브·6보스·은신/행동 예고 후속도 반영했다. 독립 통제 화면은 허브/보스93점, 추가 은신/행동 예고94점으로 통과했다.

최종 소스의 같은 정책/시드 봇6판은 3승(C01/C04/C05),1마감,2사망이었고 오류0·동일입력 재현을 확인했다. 시각 전용 후속과 장식효과100예산은 전투 상태/난수/종료 판정 동등성을 별도17검사로 검증했다. 필수 예고·pulse·표식·미지정 효과는 버리지 않으며 필수효과만 예산을 넘으면 보존한다. 독립 압박 fixture에서 효과 수311→100이었으나 평균 tick5.066ms는 동일했고 CPU개선을 주장하지 않는다. 이는 macOS headless tick벽시계이며 실제 FPS/기기 성능이 아니다.
